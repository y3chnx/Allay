# What is it?

Allay Motifs is an open-source music motif maker. It generates a short piece of music. People can upload an audio file that they already have and download the audio file that they created. Everyone can use and change it under the [MIT License](LICENSE).

<br>

# How to run locally
Clone the repository. You can use this command to clone:
```
git clone https://github.com/y3chnx/Allay
```
Go to the repository that you just cloned and type this: 
```
npx serve .
```
